# AdForge

**An AI agent that writes, runs, and fixes its own Blender code to produce shoppable 3D product ads.**

Built for the CreateOS × Stripe Projects Hackathon (Oct 17, 2026).

## The problem

Small brands and indie sellers need scroll-stopping product creative, but 3D ads mean hiring a motion designer or learning Blender. And even a great ad usually dead-ends: the viewer still has to go find where to buy.

## What AdForge does

You give it a product (picked from your Stripe catalog, or typed in) and a vibe. The agent:

1. **Stripe**: creates the product/price if needed and a **Payment Link** for it.
2. **Writes code**: an LLM writes a full Blender Python (`bpy`) scene script: product shape, materials, lighting, camera, 3D typography, decorations.
3. **Runs it in a CreateOS Sandbox**: headless Blender renders a fast 540p draft inside an isolated VM.
4. **Fixes itself**: if Blender throws, the traceback is fed back to the model and it rewrites the script.
5. **Looks at its own work**: a vision "art director" model scores the draft (framing, legibility, lighting, vibe) and the agent rewrites the scene from that critique.
6. **Ships**: final 1080p render (or a 48-frame looping MP4/GIF), then ffmpeg in the sandbox composites a **scan-to-buy QR code** for the Stripe Payment Link onto the ad.

The result is an ad that sells: scan the QR in the image and you land on Stripe Checkout for that exact product.

## How it works

```
Browser UI ──POST /api/jobs──▶ Node server ──▶ agent loop
                                   │
     ┌─────────────────────────────┼──────────────────────────────┐
     ▼                             ▼                              ▼
  Stripe API                LLM (OpenAI / OpenRouter)      CreateOS Sandbox (s-2vcpu-2gb, devbox:1)
  product, price,           writes bpy code, reads          Blender 4.2 headless (Cycles CPU)
  Payment Link → QR         errors, critiques drafts        + ffmpeg + adkit helper library
                                   ▲                              │
                                   └──── stdout/traceback/PNG ────┘
```

- **`src/agent.mjs`**: the write → run → fix → critique → render → composite loop. Streams every step to the UI over SSE.
- **`src/sandbox.mjs`**: finds or creates the CreateOS sandbox, installs Blender, ffmpeg, and fonts once, uploads the `adkit` library, and streams command output (`streamCommand`). The sandbox uses `auto_pause_after_seconds` so it pauses when idle and resumes on the next job with Blender already installed.
- **`sandbox/adkit.py`**: a small Blender helper library the agent codes against (`backdrop`, `can`, `bottle`, `box`, `card`, `text`, `studio_lights`, `camera`, `turntable`, …). It keeps generated scripts short and reliable on a 2 vCPU / 2 GB CPU-only box.
- **`src/stripe.mjs`**: reads the Stripe catalog, creates products and prices, creates Payment Links, and generates QR codes.
- **`src/prompts.mjs`**: the system prompt (API surface plus ad-composition rules) and the vision critic rubric.
- **`public/index.html`**: a single-page UI showing pipeline status, live sandbox logs, each code version the agent wrote, drafts with critic scores, and the final ad with its Payment Link.

## Sponsor tech

**CreateOS Sandbox**
- Every line of model-generated code runs in an isolated CreateOS VM, never on the host.
- The agent uses `createSandbox`, `files.upload` / `files.download`, `streamCommand` for live logs, and `runCommand`.
- **Pause/resume** keeps one warm Blender box: `auto_pause_after_seconds: 900`, then `resume()` on the next job.
- Blender and ffmpeg both run inside the sandbox (rendering, video encoding, QR compositing).

**Stripe Projects**
- The stack is provisioned with `stripe projects` (`stripe projects init`, `stripe projects add createos/project`, `stripe projects add openrouter/api`). Credentials sync to `.env`.

**Stripe**
- Products, Prices, Payment Links. Every ad is shoppable.

## Run it

Requires Node 20+.

```bash
npm install

# Option A: provision the stack with Stripe Projects
stripe plugin install projects
stripe projects init
stripe projects add createos/project
stripe projects add openrouter/api
stripe projects env --pull

# Option B: write .env by hand
cat > .env <<'EOF'
CREATEOS_SANDBOX_API_KEY=...        # createos.sh/app/profile
CREATEOS_SANDBOX_BASE_URL=https://api-eu.sb.createos.sh
OPENAI_API_KEY=...                  # or OPENROUTER_API_KEY=...
LLM_MODEL=gpt-6.1-sol               # optional
LLM_EFFORT=medium                   # optional (reasoning models)
STRIPE_SECRET_KEY=sk_test_...       # optional: enables Payment Link + QR
EOF

npm start   # http://localhost:3000
```

The first job creates the sandbox and installs Blender (about 1 minute). After that a still ad takes about 2–3 minutes end to end, including the critique round. Renders are saved in `out/<job>/`.

Optional env: `SANDBOX_SHAPE` (default `s-2vcpu-2gb`), `SANDBOX_NAME`, `MAX_CRITIQUES` (default 1).

## Tech

Node.js (no framework), `@nodeops-createos/sandbox`, Blender 4.2 LTS (Cycles CPU), ffmpeg, OpenAI-compatible LLM API (gpt-6.1-sol for code and vision critique), Stripe Node SDK, `qrcode`.
